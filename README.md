# 인스타 카드뉴스 자동화 설계안

쓰레드 자동화(threads-auto)의 구조를 그대로 가져오고, 인스타에 맞게 바꿀 부분만 새로 만듭니다.

## 1. gil님이 정한 규칙

| 항목 | 결정 |
|---|---|
| 계정 | 인스타 프로페셔널 계정 |
| 주제 | 가전·주방 살림 꿀팁 (2026-10-21 변경, 원래 충격 뉴스 + 생활정보). 프로필 소개글과 맞추기 위해 |
| 카드 | **목록형 8~10장** (2026-10-23 벤치마킹 반영): 표지(이득 + 가전 + 활용법 N) → 팁 6~8장(번호·제목·설명 2줄) → 마무리("이건 절대 하지 마세요" + 저장 유도). 전부 같은 세트장 사진 |
| 그림 | 제미나이 실사 사진 (글씨는 코드로 얹음) |
| 디자인 | **A안 뉴스 속보형** ([비교 이미지](docs/design/디자인_3안_비교.png)) |
| 발행 | 하루 2번, 07:00 · 17:30 (2026-10-23 변경) |
| 승인 | **승인해야만 게시** (쓰레드와 다름. 안 누르면 안 올라감) |
| 텔레그램 | 인스타 전용 봇 새로 만들기 |
| 레포 | `Insta_cardnews` (새 레포) |
| 캡션·해시태그 | Claude가 매번 새로 작성 |
| 쿠팡·홍보 문구 | 나중에 추가 (자리만 만들어 둠) |
| 벤치마킹 | 나중에 캡처 보내주시면 반영 (기능은 미리 넣어 둠) |
| 쓰레드와 관계 | 완전히 따로 |

## 2. 하루 흐름

1. **초안 만들기** (21:00·08:00·14:00, cron-job.org가 깨움 → 다음 회차 초안)
   - 주제 수집: 가전·주방 키워드로 구글·네이버 뉴스 검색 (7일 이내). 기사가 없으면 계절 꿀팁
   - Claude: 제목 1장 + 본문 3장 + CTA 문구 + 캡션 + 해시태그 작성
   - 제미나이: 카드마다 배경 실사 사진 생성 (글씨·얼굴 없이)
   - 코드(Pillow): 사진 위에 목록형 디자인으로 한글 글씨 얹기 → 1080×1350 이미지 8~10장
   - 텔레그램 전용 봇으로 카드 묶음 + 캡션 + 버튼 발송
2. **버튼 확인** (10분마다): ✅ 승인 / 🔄 다시 쓰기 / 🖼 사진만 다시 / ⏭ 건너뛰기
3. **게시 (07:00·17:30)**: ⏭ 누르지 않은 것은 인스타 캐러셀(여러 장 넘기기)로 게시 → 텔레그램으로 링크 알림
   - 승인을 안 눌러도 게시 시각이 되면 자동 게시 (2026-10-20 gil 요청). ⏭ 안 올리기를 누른 회차만 건너뜀

초안을 게시 3~10시간 전에 만드는 이유: 승인하실 시간을 드리기 위해서입니다. 아침 7시 회차는 전날 밤 9시에 와요.

## 3. 파일 구조

```
Insta_cardnews/
├─ .github/workflows/
│   ├─ draft.yml        # 초안 만들기
│   └─ poll.yml         # 버튼 확인 + 게시
├─ src/
│   ├─ trends.py        # 쓰레드에서 가져옴
│   ├─ writer.py        # Claude 대본 (목록형 8~10장)
│   ├─ images.py        # 제미나이 배경 사진
│   ├─ render.py        # 새로 만듦: 사진 + 한글 글씨 합성
│   ├─ telegram.py      # 쓰레드에서 가져옴 (사진 묶음 발송 추가)
│   ├─ instagram.py     # 새로 만듦: 캐러셀 게시
│   ├─ hosting.py       # 쓰레드에서 가져옴: 카드 사진을 임시 공개 주소로 올림
│   ├─ draft.py         # 초안 저장·텔레그램 표시·버튼
│   ├─ make_draft.py
│   └─ poll.py
├─ prompts/persona.md   # 카드뉴스용 말투·규칙
├─ fonts/               # Pretendard (무료 상업용 글꼴)
├─ drafts/<날짜>/       # draft.json + bg1~N.jpg(배경) + card1~N.jpg(완성, 8~10장)
└─ state/               # 텔레그램 오프셋, 거절한 이슈, 벤치마킹
```

## 4. 인스타만의 주의점

1. **사진은 공개 주소로만 올릴 수 있음.** 인스타 API가 사진을 직접 받지 않고, 인터넷 주소를 받아서 가져갑니다.
   - 게시 직전에 쓰레드 자동화와 같은 임시 사진 저장소(hosting.py)에 올려 주소를 만듭니다. 키·토큰은 GitHub Secrets에만 있어서 레포가 공개여도 안전합니다.
2. **인스타 토큰은 60일마다 만료** (인스타 로그인 방식일 때). 자동 갱신은 다음 단계에서 붙입니다. 페이스북 페이지 연결 방식의 페이지 토큰은 만료가 없습니다.
3. **사진 형식은 JPG만.** render.py가 JPG로 저장합니다.
4. 하루 게시 한도(24시간 50개)는 하루 1번이라 걱정 없음.

## 6. 알람 (cron-job.org, 쓰레드와 같은 방식)

| 작업 | 주소 | 시간 (한국) |
|---|---|---|
| 초안 만들기 | `POST https://api.github.com/repos/pmpdoit73-lang/Insta_cardnews/actions/workflows/draft.yml/dispatches` | 매일 08:00, 14:00, 21:00 |
| 버튼 확인·게시 | `.../workflows/poll.yml/dispatches` | 06:00~23:50, 10분마다 |

게시는 하루 2번 **07:00 · 17:30** (2026-10-23 gil 요청으로 3번에서 변경).
초안 만들기는 실행될 때마다 "다음 회차"를 알아서 고른다: 21:00 → 다음 날 07:00, 08:00 → 17:30. 14:00 알람은 17:30 초안이 이미 있으면 그냥 넘어간다(지워도 됨).

본문(body): `{"ref":"main"}` · 헤더: 쓰레드 때 만든 PAT에 이 레포 권한 추가 필요

## 7. 남은 일

- 인스타 토큰 60일 자동 갱신 (`instagram.refresh_token()`은 준비됨, Secrets 자동 저장은 아직)
- 쿠팡·홍보 문구 (gil이 나중에 추가하기로 함)

## 8. 작업 순서

1. ✅ 디자인 확정 (A안)
2. ✅ `Insta_cardnews` 레포 만들기·연결
3. ✅ 코드 작성 (카드 합성·대본·사진·텔레그램·인스타 게시)
4. gil님: 텔레그램 새 봇 만들기, 인스타 토큰 발급 → Secrets 등록 (단계별 안내 드림)
5. 시험 실행: 초안만 만들어 텔레그램으로 받아보기
6. 시험 게시 1회 확인 후 cron-job.org 알람 등록
