# 인스타 카드뉴스 자동화 설계안

쓰레드 자동화(threads-auto)의 구조를 그대로 가져오고, 인스타에 맞게 바꿀 부분만 새로 만듭니다.

## 1. gil님이 정한 규칙

| 항목 | 결정 |
|---|---|
| 계정 | 인스타 프로페셔널 계정 |
| 주제 | 가전·주방 살림 꿀팁 (2026-10-21 변경, 원래 충격 뉴스 + 생활정보). 프로필 소개글과 맞추기 위해 |
| 카드 | **목록형 8~10장** (2026-10-23 벤치마킹 반영): 표지(이득 + 가전 + 활용법 N) → 팁 6~8장(번호·제목·설명 2줄) → 마무리("이건 절대 하지 마세요" + 저장 유도). 전부 같은 세트장 사진 |
| 그림 | 제미나이 실사 사진 (글씨는 코드로 얹음) |
| 디자인 | **A안 뉴스 속보형** ([비교 이미지](docs/design/디자인_3안_비교.png)) |
| 인포그래픽형 | **17:30 회차** (2026-10-30~): 한 장짜리 총정리표(번호 칸 10개 또는 7개, 칸마다 만화 그림 + 숫자 배지, 가운데 "저장!" 칸, 마지막 "체크" 칸) + 저장·주의 카드 = 2장. 그림은 제미나이, 칸·한글은 Pillow. 캡션에 항목 목록을 다시 적음 |
| 댓글 | 새 댓글에 자동 답글 (2026-11-06~): 10분마다 최근 게시물 10개의 댓글 수를 보고, 늘어난 게시물만 읽어 Claude가 1~2문장 답글. 광고·스팸·욕설은 넘김, 7일 넘은 댓글 제외, 한 번에 최대 10개. 단 답글은 텔레그램으로 알림 (src/comments.py). 이슈풀이 계정도 같이 봄 (Secret `ISSUEPURI_INSTAGRAM_ACCESS_TOKEN`, 2026-11-06~) |
| 조회수 개선 (2026-11-06~) | 매일 밤 9시 두 계정 숫자 보고서(팔로워·비팔로워 도달 비율·게시물별 조회/저장/공유) 텔레그램 (`src/insights.py`, Actions '통계 보고서 지금 받기'로 즉시). 게시 직후 표지를 **스토리**에도 공유. 17:30 총정리표는 월·수·금 **쓰레드 홍보 글** (Secret `THREADS_PROMO_TOKEN` 있을 때만, `src/threads_promo.py`) |
| 발행 | 하루 2번, 07:00(목록형, **릴스 영상**) · 17:30(인포그래픽형, 캐러셀) (2026-10-23 변경, 2026-10-30 형식 분리, 2026-11-04 07:00 릴스로) |
| 승인 | **승인해야만 게시** (쓰레드와 다름. 안 누르면 안 올라감) |
| 텔레그램 | 인스타 전용 봇 새로 만들기 |
| 레포 | `Insta_cardnews` (새 레포) |
| 캡션·해시태그 | Claude가 매번 새로 작성. 2026-11-06~: 캡션 첫 줄에 검색 키워드, 저장·공유 유도 한 줄, 해시태그 3~5개 |
| 쿠팡·홍보 문구 | 나중에 추가 (자리만 만들어 둠) |
| 벤치마킹 | 나중에 캡처 보내주시면 반영 (기능은 미리 넣어 둠) |
| 쓰레드와 관계 | 완전히 따로 |

## 2. 하루 흐름

1. **초안 만들기** (21:00·08:00·14:00, cron-job.org가 깨움 → 다음 회차 초안)
   - 주제 수집: 가전·주방 키워드로 구글·네이버 뉴스 검색 (7일 이내). 기사가 없으면 계절 꿀팁
   - Claude: 제목 1장 + 본문 3장 + CTA 문구 + 캡션 + 해시태그 작성
   - 제미나이: 카드마다 배경 실사 사진 생성 (글씨·얼굴 없이)
   - 코드(Pillow): 사진 위에 목록형 디자인으로 한글 글씨 얹기 → 1080×1350 이미지 8~10장
   - 텔레그램 전용 봇으로 카드 묶음 + 캡션 + 버튼 발송
2. **버튼 확인** (10분마다): ✅ 승인 / 🔄 다시 쓰기 / 🖼 사진만 다시 / ⏭ 건너뛰기
3. **게시 (07:00·17:30)**: ⏭ 누르지 않은 것은 게시 → 텔레그램으로 링크 알림
   - 07:00 목록형: 카드를 약 15초 세로 영상(MP4)으로 만들어 **릴스**로 게시 (`src/video.py`, ffmpeg). 2026-11-06~ 맨 위 노란 띠 첫 화면 문구 + 무료 배경음악(`music/`, FreePD CC0, `src/music.py`)
   - 17:30 인포그래픽형: 인스타 캐러셀(여러 장 넘기기)로 게시
   - 승인을 안 눌러도 게시 시각이 되면 자동 게시 (2026-10-20 gil 요청). ⏭ 안 올리기를 누른 회차만 건너뜀

초안을 게시 3~10시간 전에 만드는 이유: 승인하실 시간을 드리기 위해서입니다. 아침 7시 회차는 전날 밤 9시에 와요.

## 3. 파일 구조

```

├─ .github/workflows/
│   ├─ draft.yml        # 초안 만들기
│   └─ poll.yml         # 버튼 확인 + 게시
├─ src/
│   ├─ trends.py        # 쓰레드에서 가져옴
│   ├─ writer.py        # Claude 대본 (목록형 8~10장)
│   ├─ images.py        # 제미나이 배경 사진
│   ├─ render.py        # 새로 만듦: 사진 + 한글 글씨 합성
│   ├─ telegram.py      # 쓰레드에서 가져옴 (사진 묶음 발송 추가)
│   ├─ instagram.py     # 새로 만듦: 캐러셀·릴스 게시
│   ├─ video.py         # 카드 → 릴스용 세로 영상(MP4)
│   ├─ hosting.py       # 쓰레드에서 가져옴: 카드 사진을 임시 공개 주소로 올림
│   ├─ draft.py         # 초안 저장·텔레그램 표시·버튼
│   ├─ make_draft.py
│   └─ poll.py
├─ prompts/persona.md   # 카드뉴스용 말투·규칙
├─ fonts/               # Pretendard (무료 상업용 글꼴)
├─ drafts/<날짜>/       # draft.json + bg1~N.jpg(배경) + card1~N.jpg(완성, 8~10장)
└─ state/               # 텔레그램 오프셋, 거절한 이슈, 벤치마킹
```

## 4. 인스타만의 주의점

1. **사진은 공개 주소로만 올릴 수 있음.** 인스타 API가 사진을 직접 받지 않고, 인터넷 주소를 받아서 가져갑니다.
   - 게시 직전에 쓰레드 자동화와 같은 임시 사진 저장소(hosting.py)에 올려 주소를 만듭니다. 키·토큰은 GitHub Secrets에만 있어서 레포가 공개여도 안전합니다.
2. **인스타 토큰은 60일마다 만료** (인스타 로그인 방식일 때). 자동 갱신은 다음 단계에서 붙입니다. 페이스북 페이지 연결 방식의 페이지 토큰은 만료가 없습니다.
3. **사진 형식은 JPG만.** render.py가 JPG로 저장합니다.
4. 하루 게시 한도(24시간 50개)는 하루 1번이라 걱정 없음.

## 6. 알람 (cron-job.org, 쓰레드와 같은 방식)

| 작업 | 주소 | 시간 (한국) |
|---|---|---|
| 초안 만들기 | `POST https://api.github.com/repos/pmpdoit73-lang/Insta_cardnews/actions/workflows/draft.yml/dispatches` | 매일 08:00, 14:00, 21:00 |
| 버튼 확인·게시 | `.../workflows/poll.yml/dispatches` | 06:00~23:50, 10분마다 |

게시는 하루 2번 **07:00 · 17:30** (2026-10-23 gil 요청으로 3번에서 변경).
초안 만들기는 실행될 때마다 "다음 회차"를 알아서 고른다: 21:00 → 다음 날 07:00, 08:00 → 17:30. 14:00 알람은 17:30 초안이 이미 있으면 그냥 넘어간다(지워도 됨).

본문(body): `{"ref":"main"}` · 헤더: 쓰레드 때 만든 PAT에 이 레포 권한 추가 필요

## 6-1. 아침 소통 안내 (2026-11-10, engage.py)

- 매일 **08:00 이후 첫 실행** 때 텔레그램으로 "오늘의 소통"을 보냄: 둘러볼 해시태그 2개 + 살림 계정 3개 링크, 상황별 댓글 초안 5개 (글씨를 누르면 복사)
- 마음에 드는 게시물을 **캡처하거나 캡션을 복사해 봇에 보내면** 10분 안에 그 글에 맞춘 댓글 3개를 답장
- 좋아요·댓글은 **gil이 직접**. 남의 게시물에 자동으로 좋아요·댓글 다는 기능은 인스타 공식 API에 없고, 비공식 자동화는 계정 정지 위험
- 둘러볼 계정 목록: `prompts/engage_accounts.txt` (한 줄에 하나)
- 해시태그 인기 게시물 자동 추천은 페이스북 페이지 연결 방식(`INSTAGRAM_API_HOST=graph.facebook.com`)에서만 동작 (인스타 로그인 방식 API엔 해시태그 검색이 없음)
- 지금 바로 받기: Actions → "소통 안내 지금 받기"

## 6-2. 12:00 스킬형 회차 추가 (2026-11-12)

기존 07:00 목록형 릴스·17:30 총정리표는 **그대로** 두고, 12:00에 '스킬형' 릴스 하나를 더 올림.
공개 스킬 [instagram-agent-skill](https://github.com/Jakeschincariol/instagram-agent-skill) (MIT)의 규칙을 이 회차에만 적용.
초안 알람(08·14·21시)은 그대로: 08시 알람이 12:00 초안을 만든다.

- 카드: 표지 → **2번 '왜 알아야 할까요'** → 팁 5~6 → **한눈에 정리** → 경고·저장 (최대 10장, 약 16.5초)
- 표지 제목 2줄 합쳐 6어절 이내(개수 숫자 빼고), 캡션 첫 125자 안에 키워드 + 숫자
- 첫 화면 문구: 훅 공식 26개(`prompts/hook_formulas.md`) 중 3개로 써 보고 점수 높은 것. 마지막 카드에선 같은 낱말을 다시 쓰는 문구(loop_line)로 바뀜
- 터진 릴스 분석(`src/viral.py`): 참고 계정 릴스 탭 캡처를 '벤치'라고 적어 봇에 보내면, 평소(중간값)의 몇 배인지·훅 공식·우리 버전 문구를 답장. 기록(`state/swipe.json`)은 스킬형 훅 쓸 때 참고
- 일요일 숫자 보고서에 '이번 주 성적표' ((공유+저장)÷도달 순위, 릴스 vs 총정리표)
- 몇 주 뒤 숫자 보고서로 07:00(기존)과 12:00(스킬형)을 비교해서, 좋으면 기존 회차에도 넓히기

## 8. 작업 순서

1. ✅ 디자인 확정 (A안)
2. ✅ `Insta_cardnews` 레포 만들기·연결
3. ✅ 코드 작성 (카드 합성·대본·사진·텔레그램·인스타 게시)
4. gil님: 텔레그램 새 봇 만들기, 인스타 토큰 발급 → Secrets 등록 (단계별 안내 드림)
5. 시험 실행: 초안만 만들어 텔레그램으로 받아보기
6. 시험 게시 1회 확인 후 cron-job.org 알람 등록
