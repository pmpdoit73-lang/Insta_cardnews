# 인스타 카드뉴스 자동화 설계안

쓰레드 자동화(threads-auto)의 구조를 그대로 가져오고, 인스타에 맞게 바꿀 부분만 새로 만듭니다.

## 1. gil님이 정한 규칙

| 항목 | 결정 |
|---|---|
| 계정 | 인스타 프로페셔널 계정 |
| 주제 | 충격 뉴스 + 생활정보 |
| 카드 | 5장: 1장 제목 → 2~4장 본문 → 5장 CTA(저장·공유·팔로우) |
| 그림 | 제미나이 실사 사진 (글씨는 코드로 얹음) |
| 디자인 | A/B/C 3안 중 선택 ([비교 이미지](docs/design/디자인_3안_비교.png)) |
| 발행 | 하루 1번, 저녁 7시 |
| 승인 | **승인해야만 게시** (쓰레드와 다름. 안 누르면 안 올라감) |
| 텔레그램 | 인스타 전용 봇 새로 만들기 |
| 레포 | `Insta_cardnews` (새 레포) |
| 캡션·해시태그 | Claude가 매번 새로 작성 |
| 쿠팡·홍보 문구 | 나중에 추가 (자리만 만들어 둠) |
| 벤치마킹 | 나중에 캡처 보내주시면 반영 (기능은 미리 넣어 둠) |
| 쓰레드와 관계 | 완전히 따로 |

## 2. 하루 흐름

1. **오후 3시 초안 만들기** (cron-job.org가 깨움)
   - 이슈 수집: 쓰레드의 `trends.py` 재사용 (구글·네이버 뉴스, 36시간 이내)
   - Claude: 제목 1장 + 본문 3장 + CTA 문구 + 캡션 + 해시태그 작성
   - 제미나이: 카드마다 배경 실사 사진 생성 (글씨·얼굴 없이)
   - 코드(Pillow): 사진 위에 정한 디자인으로 한글 글씨 얹기 → 1080×1350 이미지 5장
   - 텔레그램 전용 봇으로 5장 + 캡션 + 버튼 발송
2. **버튼 확인** (20분마다): ✅ 승인 / 🔄 다시 쓰기 / 🖼 사진만 다시 / ⏭ 건너뛰기
3. **저녁 7시 게시**: 승인된 것만 인스타 캐러셀(여러 장 넘기기)로 게시 → 텔레그램으로 링크 알림
   - 7시까지 승인이 없으면 게시하지 않고 "오늘은 안 올렸어요" 알림

초안을 오후 3시에 만드는 이유: 승인하실 시간을 4시간 드리기 위해서입니다. 시간은 바꿀 수 있어요.

## 3. 파일 구조 (계획)

```
Insta_cardnews/
├─ .github/workflows/
│   ├─ draft.yml        # 초안 만들기
│   └─ poll.yml         # 버튼 확인 + 게시
├─ src/
│   ├─ trends.py        # 쓰레드에서 가져옴
│   ├─ writer.py        # Claude 대본 (5장 구조로 수정)
│   ├─ images.py        # 제미나이 배경 사진
│   ├─ render.py        # 새로 만듦: 사진 + 한글 글씨 합성
│   ├─ telegram.py      # 쓰레드에서 가져옴 (사진 묶음 발송 추가)
│   ├─ instagram.py     # 새로 만듦: 캐러셀 게시
│   ├─ make_draft.py
│   └─ poll.py
├─ prompts/persona.md   # 카드뉴스용 말투·규칙
├─ fonts/               # Pretendard (무료 상업용 글꼴)
├─ drafts/<날짜>/       # card1~5.jpg + draft.json
└─ state/               # 텔레그램 오프셋, 거절한 이슈, 벤치마킹
```

## 4. 인스타만의 주의점

1. **사진은 공개 주소로만 올릴 수 있음.** 인스타 API가 사진을 직접 받지 않고, 인터넷 주소를 받아서 가져갑니다.
   - ★추천: `Insta_cardnews` 레포를 **공개(public)**로 만들면 레포 안 사진 주소를 그대로 씁니다. 키·토큰은 GitHub Secrets에 숨겨져 있어서 공개돼도 안전합니다.
   - 다른 방법: 레포는 비공개, 사진만 올리는 공개 레포를 하나 더 만들기.
2. **인스타 토큰은 60일마다 만료.** 코드가 50일쯤에 자동으로 새로 받아 두도록 만듭니다.
3. **사진 형식은 JPG만.** render.py가 JPG로 저장합니다.
4. 하루 게시 한도(24시간 50개)는 하루 1번이라 걱정 없음.

## 5. 필요한 키 (GitHub Secrets에만 저장)

| 이름 | 쓰레드에서 재사용 | 비고 |
|---|---|---|
| ANTHROPIC_API_KEY | ✅ | |
| GEMINI_API_KEY | ✅ | |
| NAVER_CLIENT_ID / SECRET | ✅ | 뉴스 수집 |
| YOUTUBE_API_KEY | ✅ | 인기 이슈 |
| TELEGRAM_BOT_TOKEN | ❌ 새로 | 인스타 전용 봇 (BotFather에서 생성) |
| TELEGRAM_CHAT_ID | ✅ 같아도 됨 | gil님 채팅방 |
| INSTAGRAM_ACCESS_TOKEN | ❌ 새로 | 메타 개발자 앱에서 발급 |
| INSTAGRAM_USER_ID | ❌ 새로 | 위와 함께 확인 |

## 6. 작업 순서

1. 디자인 확정 (A/B/C)
2. gil님: GitHub에 `Insta_cardnews` 레포 만들기 → Claude에게 연결
3. Claude: 코드 작성 (render.py부터, 샘플 카드 5장 먼저 보여드림)
4. gil님: 텔레그램 새 봇 만들기, 인스타 토큰 발급 → Secrets 등록 (단계별 안내 드림)
5. 시험 실행: 초안만 만들어 텔레그램으로 받아보기
6. 시험 게시 1회 확인 후 cron-job.org 알람 등록
